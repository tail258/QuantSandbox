# 数据与计算口径 v0.1.0

## 数据与缓存

每个成功抓取生成不可变 JSON 内容快照，含原始财报、规范化字段、完整请求、来源 URL、抓取 UTC 时间、方法与代码版本。SQLite 存储，内容哈希作为 ID。按数据类型/标的选择最新快照，完全相同请求在 24 小时内复用；强制更新可以绕过 TTL。更新失败只有请求完全相同才返回旧缓存，并显示失败原因。

价格默认不复权（3），可选前复权（2）或后复权（1）。BaoStock 为主，明确错误时尝试东方财富；整个调用 55 秒超时。前/后复权含未来分红调整的影响，不等于历史时点可交易价格。PE/PB 直接来自数据商，不用非同期利润自行推算；备用源缺估值时留空。

初版按请求范围重新获取完整区间，尚未做分段增量补齐。结果以参数与快照内容生成记录 ID；相同分析复用记录，计算本身仍会快速执行以验证结果。

## 财务

利润表和现金流量表：单季 Q1 = Q1 累计；Q2 = 半年 − Q1；Q3 = 前三季 − 半年；Q4 = 年报 − 前三季。不存在相邻前期时返回 null，不将年累计视为单季。

资产、负债保持报告期末余额。毛利率 = (单季营收 − 单季成本)/单季营收；归母净利率 = 单季归母净利/单季营收；现金比率 = 单季经营现金流/单季归母净利；资产负债率 = 期末负债/期末资产。零分母返回 null；负利润下现金比率需结合原数阅读。归母口径与合并经营现金流口径不完全相同，须结合少数股东影响。

公告日取三张报表可得的最晚日期，拆季另考虑前期公告日；未知不伪造日期。当前来源可能有追溯调整、不同修订版本混合；原始报表随快照保留，重大变化应回原公告核验。公司间报告期可能不同，表格明确列出期末日期。银行与保险模板的专用指标需要补充，模板仅引导分析，不生成虚构行业指标。

## 统计

输入由固定快照和字段 ID 指定。先以 available_date 为索引；同一天多次公布取最后一条（导入表按观测日排序），再选日度或以周五/月末为标签的区间最后值。所有序列必须有真实可用日期；价格可用日按收盘当天处理，不支持日内时点。

X 与 Y 精确内连接，不 forward fill。变换在选定区间及共同观测上进行：水平、差分或 pct_change。日频有缺口时，一期就是两个连续共同观测，未必连续交易日。

正 lag：corr(X(t), Y(t+lag))；负 lag 只作相关探索。条件概率使用 X 变换值大于/小于阈值时，Y(t+lag+horizon)/Y(t+lag)−1 > 0 的比例。即先等待 lag 期，再观察 horizon 期。基准来自相同日期、样本规则下的无条件概率。零变化不算上涨；最终不足 horizon 的样本不纳入。

排除重叠时从有效观测起，每 max(1, lag+horizon) 期保留一次，先取样再判断条件，因此基准和条件使用同一网格。95% Wilson 区间按二项比例计算；金融序列可能存在剩余相关，区间未修正序列相关；反复试参数可能产生选择偏差。初版是探索统计，不含因果识别、自动样本外评估或交易成本回测。

统计参数文件示意（序列 ID 请从 CLI series 获取）：

```json
{"x":"SNAPSHOT:close","y":"SNAPSHOT:close","start":"2023-01-01","end":"2026-10-28","frequency":"D","transform":"returns","lag":2,"horizon":5,"operator":"gt","threshold":0.01,"nonoverlap":true}
```

## 产业与情绪

RU0 为新浪数据商主力连续，拼接/换月规则未披露，不能当作无摩擦可交易连续收益。周期图按观测日显示；多序列首个有效值归一化为 100，不因量纲不同直接计算原值价差。报价差只匹配同日期同单位，未自动转换税费、地区或交割品质。

情绪样本是本地最新缓存股票，使用最新共有行情日的有效涨跌幅；不等于全市场。MA20 使用可得 20 行收盘；成交额相对值为当日 / 包含当日的近20行均额。短历史样本须额外注意覆盖。

## 导出与复算

每条统计记录包含方法文本、参数、输入快照ID、数据源与结果；财务记录还保存各公司配置与变换结果。ZIP 包含原始输入快照、recipe、report、CSV 与 SVG；统计图是各序列区间最小最大归一化，图中说明不同于原值图，避免误读。财务图以选定指标的原数值同轴展示，单位和范围标在图中；缺失季度断线。

`replay` 以原快照重算统计并比较；财务记录读取归档变换结果（未来版本可加重新推导对比）。重新获取数据再分析是新记录。未自动跨版本迁移旧公式；升级后比较 version 与结果差异。
