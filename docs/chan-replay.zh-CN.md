# 日线缠论结构与重放

在研究项目中打开「缠论结构」，选定一份已有的未复权日线快照。也可以用离线示例查看完整结构。分析使用快照里的固定数据，不请求行情。逐根推进或拖动日期时，画面只显示截至该根日线收盘时计算出的结构。

## 读图

- 原始 K 线保留未复权价格。分型在处理包含关系后的 K 线序列上识别，投影回实际产生高低点的交易日。
- 严格笔连接相反分型，要求两个分型的中心在合并序列中至少相隔四个位置，且顶分型的高低两端都高于底分型。等价的高点或低点保留先出现者。序列开头等待明确方向，再处理之前暂定的包含关系。
- 线段至少由三笔构成，其结束依据反向笔的标准特征序列。第一、第二特征元素之间有缺口时，等待后续反向特征分型。也识别转折第一笔即破坏原线段、后续同向笔继续突破该笔终点的情形。
- 中枢以连续三段端点价格区间首次形成的正宽度交集为上下沿。后续线段按往返成对考察延伸，同向确认段离开该区间时结束当前中枢。若相邻中枢的上下沿分离、外围波动区间却接触或重叠，记录为扩张候选，供日线研究核查。
- 结构的几何日期、首次可见日和确认日分别记录。尾部候选结构随新 K 线变化，当日变化可以在时间轴上回看。候选结构可能移动或撤销。

包含和分型参考[第 62 课](https://chanlun108.cn/chanzhongshuochan108ke/62)和[第 65 课](https://chanlun108.cn/chanzhongshuochan108ke/65)。线段参考[第 67 课](https://chanlun108.cn/chanzhongshuochan108ke/67)和[第 71 课](https://chanlun108.cn/chanzhongshuochan108ke/71)。中枢定义参考[第 17 课](https://chanlun108.cn/chanzhongshuochan108ke/17)和[第 20 课](https://chanlun108.cn/chanzhongshuochan108ke/20)。用[公开版 chan.py 指南](https://github.com/Vespa314/chan.py/blob/main/quick_guide.md)核对逐根更新、候选结构与缺口情形。

## 数据和证据

日线重放使用固定的历史版本。每一帧仅使用该日及此前的输入，快照的获取时间另行记录。若行情源事后订正旧数据，新的快照可能得到不同的结构。用未复权价格识别时，除息跳空也会参与识别。证据记录快照内已知的现金分红除息日、被排除的已知停牌和数据覆盖缺口，缺失日期不补线。算法按剩余观测的顺序连接结构，核对跨越缺口的结构时请同时看覆盖记录。

下载原始 JSON 证据后，可在工作台重新导入。验证根据证据里的日线重新计算全部结构和重放事件，核对输入、算法版本和结果哈希。离线示例的合成数据单独标记。真实证据中含本地研究输入，按工作区研究档案管理。

在已安装工作台的 Windows 上，也可不启动服务导出示例和核对证据：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m backend.workbench.cli chan-demo --output chan-demo-evidence.json
.\.venv\Scripts\python.exe -X utf8 -m backend.workbench.cli chan-replay chan-demo-evidence.json
```

当前范围为单标的日线结构。交易信号、背驰和买卖点，以及跨周期走势中枢属于后续研究。
