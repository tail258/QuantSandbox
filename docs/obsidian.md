# Obsidian 模块

这是可选的通用笔记对接模块，适用于任意本机 Obsidian 笔记库。未配置时也可完整使用研究、回测与导出功能。模块没有默认私人仓库名称或路径，不读取、索引或上传笔记库内容。

## 默认使用：下载附件包

在 Obsidian 页面选择一条已保存的研究分析或已完成的模拟实验，填写可选标题和备注，点击预览，再下载 ZIP。包内包含 Markdown、计算参数、来源与冻结输入标识、完整结果，以及适用的 SVG 图表。解压后把笔记和同名 `.assets` 文件夹一起复制到笔记库，图片与附件链接保持相对路径。

来源附件保存原始 URL、数据单位、获取时间、请求口径和快照标识；模拟快照保留内容哈希。结果中的样本量、缺失值和统计区间保留，不把当前修订数据当作历史时点数据。便携包不包含笔记库路径或其他本机绝对路径。

## 可选：手动写入本机笔记库

1. 填写已经存在的本机笔记库绝对路径，选择相对子目录，启用并保存配置。默认子目录为 `QuantSandbox`。
2. 选择记录并预览；预览展示将生成的 Markdown 和附件清单。
3. 点击“写入笔记库”执行这一次写入。没有后台同步、定时写入或自动归档。

配置只保存在当前数据目录下 `.local/obsidian.json`，由 Git 忽略，不进入导出包；通过独立数据目录运行测试时配置也独立。关闭模块只停用写入，不删除配置或已经导出的笔记。

写入需携带本次预览令牌，标题、备注、结果或配置变化后必须重新预览；服务重启也会使令牌失效。笔记和附件均以新文件创建，已存在任意目标文件则整次拒绝，不覆盖内容。改用其他标题可生成新的记录。失败时撤回本次创建的文件。

不能使用网络路径、相对笔记库路径、`..`、隐藏子目录、`.obsidian`、符号链接或目录联接。模块不枚举笔记库，不读取既有笔记，不改 Obsidian 插件和设置。

## API

| 操作 | 接口 | 内容 |
| --- | --- | --- |
| 配置 | `GET /api/obsidian/config` | 默认 `enabled=false`、空路径 |
| 保存配置 | `PUT /api/obsidian/config` | `{enabled,vault_path,folder}`，仅本机保存 |
| 预览 | `POST /api/obsidian/preview` | `{kind,run_id,title?,notes?}`；返回 Markdown、文件清单、`preview_token` |
| 下载 | `POST /api/obsidian/export` | 相同参数，返回 ZIP；无需笔记库配置 |
| 单次写入 | `POST /api/obsidian/publish` | 相同参数加 `preview_token`；仅启用后可用 |

`kind` 为 `research` 或 `simulation`。写入响应只返回笔记库内的相对文件名；便携导出不包含本机配置。模拟研究的原始可复算证据包仍从实验页单独导出，Obsidian 附件包用于携带结论和引用，二者职责不同。
