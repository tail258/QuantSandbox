# 个股与 ETF 研究

从工作台首页输入沪深六位股票或场内 ETF 代码，也可直接点研究项目中的证券代码。页面只更新当前标的；更新期间显示已保存快照，暂停展示触发条件。「市场背景」提供宽基参考和已有的市场观察入口。

1. **当前判断** 根据近期确认的高低分型和所处结构说明为什么观望，显示最新成交量与此前均量的比值。
2. **观察交易日** 显示下一已知交易日。行情和结构支持时，列出放量突破、触及后收复或支撑失效的条件，点击可在 K 线上定位依据。条件用完整日线确认，执行顺延到后续可交易日，并需重新核对价格、成交可行性和成本。
3. **日线 / 周线** 可切换分型、笔、线段、中枢等图层。形态画在发生日，可用性以确认日为准。周线按交易日历汇总完整交易周，缺口后重新建立连续序列；周线背景不会改变日线触发条件。
4. **跟踪因子** 可按标的、项目分别保存。选项包括 20/60 日简单均线、14 日 RSI（滚动简单均值）、20 日布林带（总体标准差，倍数 2）与相对成交量（此前 20 个有效成交日，不含当天）。因子仅供描述，因子勾选不改写交易规则。
5. **历史事件研究** 手动比较同一标的、同一规则的触发样本和符合资格但未触发的对照。按交易日历对齐，用后续开盘价作为参考，显示排除原因与成本敏感性。这不是可成交回测：无法核实盘口或历史涨跌停队列，重叠窗口也不是独立样本。
6. **行情来源、计算口径与回看** 提供行情源、交易日历、采集时间、快照和 SHA-256。历史回看先切截至该日的日线再重新计算，停用实时条件；现存的历史快照可能含来源修订，不能替代当时真正采集到的版本。

BaoStock 提供已完成日线、交易日历和证券身份。日线保持未复权；明确停牌、缺线和前收参考跳变分别处理。上海时间 16:30 后才请求当日收盘价；从 15:00 收盘到来源更新前，旧的观察条件会到期。未复权价格可用于核对报价和观察价位，跨公司行动的价格变化不代表总回报。

计划以价格当前仍在其中的近期已确认中枢为优先参考，找不到再检查近端已确认分型。入场场景需要收盘确认、此前 20 个有效交易日均量的 1.25 倍和基于已确认上方分型的名义空间。上限按适用报价单位向下取整。中枢外侧回抽则单独记录：中枢先确认，之后出现连续的离开与反向回抽线段，原始 K 线在反抽至确认期间始终留在边界外。只在首次可见的确认日标记；后来触及边界会更新观察状态。

「日线中枢外侧回抽」只描述结构。正式三类买卖点还需可验证的次级别走势；一类、二类和背驰还需经验证的走势分解、力度比较和相应阈值，尚未用于生成交易条件。现有美股研究入口保留，未接入同一套多标的条件页。本轮没有启用定时采集或向 GitHub 同步快照和项目数据。

Codex 可通过本地 MCP 读取已保存快照、按请求刷新单标的、查阅历史研究和保存因子选择。见 [Codex 工作流](codex-workflow.zh-CN.md)。
