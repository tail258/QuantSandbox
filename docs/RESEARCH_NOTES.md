# 计算与数据口径

## 执行与账户

收盘信号最早在该标的下一个可交易日开盘执行。多标的共享现金，按代码稳定排序、先卖后买。默认整手 100 股、T+1、最低佣金、卖出税费与双边滑点；费用计入现金和完整平仓损益。

仓位参数是每次入场的资金预算比例，除分叉调整外不每日自动再平衡。期末持仓按收盘估值，基准为不含交易费用的等权买入持有。零成交量、停牌或显式涨跌停字段可阻止成交；日线撮合不包含盘口、成交队列、成交量占比和市场冲击。

## 行情口径

真实行情当前使用未复权日线，尚未记账分红送转、退市收益和完整逐日证券规则。行情请求失败会显示错误，保留用户选择的数据来源。

演示行情覆盖 2019-01-01 至 2026-09-18，使用工作日历，未模拟交易所节假日；示例股票名称用于操作演示。界面和证据包均明确标记合成来源。

## 实验与分叉

压力实验在固定行情上重跑费用、滑点、执行延迟及仓位情景。参数比较衡量同一区间敏感性，最佳参数不是样本外证据。滚动样本外按训练窗口选参，在连续账户上执行后续测试窗口；目前没有独立的最终保留测试集。

历史分叉复用原快照，从起点确定性重放。检查点用于审计与展示；分叉当日收盘后的策略或仓位变化影响后续订单。当前从基线发起实验，分支结果暂不支持直接运行实验。

## 回放与证据

盲测模式按游标返回可见历史与重新计算的指标，揭晓状态持久保存。它用于本地练习和复盘；普通研究接口仍能访问完整结果。

证据包保存配置、OHLCV、结果、数据指纹和执行时源文件指纹。导入先校验完整性，再用当前引擎重算并报告差异。SHA256 用于内容完整性检查，不代表第三方认证。原始 JSON 文件应直接上传，避免数值重新序列化改变校验值。
